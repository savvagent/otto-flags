Use Otto Flags from your AI assistant

Otto Flags doesn't have a web page here. Add it to your AI assistant as a connector, then ask which flags are on, roll one out, or roll one back in plain language. The first time, you sign in with your Otto account.

Connector address

{{CONNECTOR_URL}}

Claude (claude.ai or the desktop app)

  1. Open Settings, then Connectors.
  2. Choose Add custom connector.
  3. Paste the connector address.
  4. Choose Connect.
  5. Sign in with your Otto account.

ChatGPT

  1. Open Settings, then Connectors (turn on developer mode if Connectors asks for it).
  2. Choose Create.
  3. Paste the connector address.
  4. Sign in with your Otto account.

Claude Code

  1. Run this in your terminal:
    claude mcp add --transport http otto-flags {{CONNECTOR_URL}}

  2. In Claude Code, run /mcp and sign in with your Otto account.
