# sdk_guide tool, served llms.txt, AGENTS.md Implementation Plan

> Execute task-by-task (fresh implementer per task, review between tasks). Steps use checkbox
> (`- [ ]`) syntax for tracking.

**Goal:** Give coding agents a tested route to the right otto-flags SDK: an MCP tool, a served
`/llms.txt`, and an `AGENTS.md`.

**Architecture:** A pure `guide` module in `flags-mcp` renders compiled-in Markdown per language
(placeholders filled from an optional app). A thin `sdk_guide` tool wraps it with the same
scope/charge/transaction pattern as its siblings. `llms.txt` has one definition in
`crates/flags-mcp/content/`, served by a static `flags-server` route, with a test-enforced copy at
the repo root.

**Tech Stack:** Rust 2021 (axum, rmcp, sqlx via flags-core), Markdown content, `#[sqlx::test]` e2e.

**Ticket:** savvagent/otto-flags#152

**Spec:** docs/specs/2026-10-22-sdk-guide-design.md

```rust
//! Per-language guides for consuming the SDKs. Read-only, free, and static apart from the named
//! app's own id and public client key.

use flags_core::apps::AppsExt;
use flags_core::scopes::FLAGS_READ;
use rmcp::handler::server::tool::Extension;
use rmcp::handler::server::wrapper::{Json, Parameters};
use rmcp::model::ErrorData;
use rmcp::{tool, tool_router};
use serde::Deserialize;

use super::out;
use crate::guide::{self, GuideError};
use crate::server::{Flags, McpResult};

#[derive(Debug, Deserialize, schemars::JsonSchema)]
#[serde(rename_all = "camelCase")]
pub struct SdkGuideArgs {
    /// The language or framework to integrate: python, typescript, node, react, vue, svelte,
    /// sveltekit, solid, angular, astro, nextjs, remix, go, java, rust, ios, android.
    pub language: String,
    /// Optional app name (or id). Fills the guide with that app's id and public client key.
    #[serde(default)]
    pub app: Option<String>,
}

#[tool_router(router = guide_router, vis = "pub(crate)")]
impl Flags {
    #[tool(
        name = "sdk_guide",
        description = "How to add an Otto Flags SDK to a project in one language or framework: \
                       install (pinned to a commit), initialize, evaluate a flag, and framework \
                       snippets. Pass `app` to fill in that app's id and public client key. \
                       Returns Markdown. Free.",
        annotations(read_only_hint = true)
    )]
    pub async fn sdk_guide(
        &self,
        Extension(parts): Extension<http::request::Parts>,
        Parameters(args): Parameters<SdkGuideArgs>,
    ) -> Result<Json<out::SdkGuideOut>, ErrorData> {
        let caller = self.caller(&parts)?;
        caller.require_scope(FLAGS_READ).mcp()?;
        // Validate before opening a transaction: a typo records nothing.
        let (language, _) = guide::render(&args.language, None).map_err(guide_error)?;
        let mut tx = self.tx(&caller).await?;
        self.charge(&mut tx, &caller, "sdk_guide").await?;
        let app = match &args.app {
            Some(name) => Some(tx.resolve_app(name).await.mcp()?),
            None => None,
        };
        tx.commit().await.mcp()?;
        let (_, text) = guide::render(language, app.as_ref()).map_err(guide_error)?;
        Ok(Json(out::SdkGuideOut {
            language: language.to_string(),
            guide: text,
            app: app.map(|a| out::GuideApp { name: a.name, id: a.id, client_key: a.client_key }),
            supported: guide::supported().into_iter().map(String::from).collect(),
        }))
    }
}
```

`guide_error` maps `GuideError::Unknown` to the invalid-argument `ErrorData` the other tools use (read `error.rs` for the constructor; message: `unknown language "<given truncated to 64 chars>"; supported: a, b, c`). `out::SdkGuideOut`/`GuideApp` are `Serialize + JsonSchema`, `camelCase`; `id` is `FlagAppId`. Note `render` is called twice (the first call validates only); if cheaper, add `guide::lookup(language) -> Result<&'static Lang, GuideError>` and use it for validation.
